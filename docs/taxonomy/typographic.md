# Typographic

Letterforms built as geometry — not live fonts in the master.

## Form vocab
- **Monogram** — 2–3 letters sharing stems
- **Single letter** — custom cut, not a default geometric sans dump
- **Wordmark** — constructed paths; optical spacing
- **Ligature-as-mark** — one fused silhouette

## Recipes
1. Shared vertical for H/N/M families.
2. Counter of O/D/C as the brand window.
3. Crossbar of A/H/E as the only expressive move.

## Failures
Unmodified system font in finals; letters that misread when tiny; decoration serifs.
