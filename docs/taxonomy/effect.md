# Effect

Same geometric base, plus one controlled operation.

## Form vocab
- **Overlay** — intersecting shapes; shared zone as third figure
- **Crop / window** — form revealed by a mask baked into paths
- **Mirror / rotation** — 180° / 90° families; check unintended faces
- **Positive/negative** — evenodd; design the hole first
- **Interlace** — weave only if junctions stay clean at 24 px

## Recipes
1. Two circles overlapping → lens as the brand idea.
2. Square cropped by a diagonal field (path boolean, not CSS clip).
3. Letter counter cut from a disc.

## Failures
Filters/shadows to fake depth; unreadable interlacing; crop that only works large.
