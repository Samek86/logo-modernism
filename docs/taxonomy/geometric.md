# Geometric

Construction from basic plane figures on a module grid.

## Form vocab
- **Squares / rects** — frames, bars, modular stacks
- **Circles / rings** — nested, offset, evenodd holes
- **Triangles / diamonds** — direction without arrows-as-cliché
- **Dots / discs** — constellations, counters, punctuation as mass
- **Grids** — 4/8/12 unit; snap edges; consistent gutters

## Recipes
1. Nested square + ring (frame holding a circular module).
2. Bar monogram: 2–3 verticals + one horizontal on odd grid.
3. Module mosaic: 3–5 tiles that still read as one silhouette at 16 px.

## Failures
Too many modules (noise at small size); unequal stroke weights; “almost” angles.
